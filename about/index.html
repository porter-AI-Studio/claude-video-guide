關於作者

本書由 Porter 主導，透過 Claude Code、opencode、Codex 三方協作整理完成，素材來自實際安裝、測試 claude-video 過程中累積的 Obsidian 筆記。

寫作方式

這本書不是先寫大綱再找資料，而是反過來：先真的把 claude-video 裝進 Claude Code 與 Codex 兩個環境、實際跑過多支影片、踩過幾個真實的坑（Windows 編碼問題、YouTube 限流、Claude Code 權限分類器擋下高風險指令），把過程整理成 Obsidian 筆記，再從這些一手筆記反推出章節結構。

每一章引用的案例、錯誤訊息、指令，都能對應回實際發生過的操作紀錄——不是憑空杜撰的範例。

一次分工實驗

本書的建立過程本身，也是一次「多個 AI 工具分工協作」的實務驗證：Claude Code 負責協調全書結構與查詢 Obsidian 素材、opencode（本機 CLI，固定模型 nemotron-3-ultra-free）承接部分資料處理工作、Codex 透過委派模式產生第 6 章的架構示意圖。這條分工路徑被證實可行，也在過程中發現並記錄了一些實務限制——例如 opencode 在非互動模式下自行寫檔會遇到權限自動拒絕的問題，因此改採「只回傳文字內容、由 Claude Code 統一寫檔」的更穩健做法。

素材來源

  • 研究筆記：claude-video 深度解析（GitCovery 影片重點）、claude-video 在 Codex 的可用性、用 Claude Code 操控 Codex 的 codex exec 實戰記錄
  • 工具筆記：claude-video（/watch skill）MOC（Map of Content，Obsidian 筆記法中彙整同主題筆記的索引頁）
  • 影片筆記：GitCovery 頻道深度解析影片、OpenAI 官方 Codex 入門簡報

本書聚焦 claude-video 在 Claude Code 與 Codex 兩個 harness 下的實戰操作與雙工具對照選型（第 5～7 章），其餘章節提供概念背景、安裝細節與延伸案例，作為完整脈絡的補充。
