前言

前言

你貼一條 YouTube 連結給 Claude，它多半只能靠標題猜——這本書要解決的就是這件事。

這本書要解決什麼問題

大型語言模型天生只處理文字，看不懂畫面、聽不懂聲音。claude-video（/watch 指令）是一個開源 Agent Skill，靠組合 yt-dlp、ffmpeg、Whisper 三個現成工具，讓 Claude 這類 LLM 真正「看懂」一支影片——而且成本壓得極低。這本書會從原理講到實戰，帶你把這套工具完整用起來。

ℹ️
兩個貫穿全書的名詞，先講清楚

Agent Skill：把一段可重複使用的工作流程（腳本＋說明文件）包裝成 AI agent 自己讀得懂、能自己呼叫執行的模組——跟寫給人類點擊使用的 App 不同，也跟後面會提到的 MCP Server 不同（MCP 是另一套協定，要另外設定連線）。Harness：本書用來泛指「執行 AI agent 的宿主環境」，例如 Claude Code、Codex、Cursor 都是不同的 harness——同一個 Agent Skill 通常能裝進多種 harness 使用，這也是本書 Part 2、Part 3 反覆對照 Claude Code／Codex 兩種 harness 的原因。

這本書適合誰

  • 已經在用 Claude Code 或 Codex，想讓 AI 幫忙處理 YouTube 影片、螢幕錄影、會議錄影的人
  • 好奇「AI 怎麼可能看懂影片」，想知道背後實際運作原理的人
  • 同時使用 Claude Code 與 Codex，想知道兩者該怎麼分工、什麼時候該用哪一個的人

關於書裡的範例

書裡引用的指令、錯誤訊息、實測結果，全部來自真實操作過程中留下的紀錄，不是憑空設計的範例。踩過的坑（Windows 編碼問題、YouTube 限流、Claude Code 權限分類器攔截）也如實記錄下來，讓你不必重踩一次同樣的坑。

這本書裡沒有一個範例是為了教學效果而設計的——每一句錯誤訊息，都是真的把環境搞壞過一次才留下來的紀錄。
